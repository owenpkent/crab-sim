# Hero crab (SK_FiddlerCrab and textures)

- Author: original work for this project.
- Licence: no third-party assets. Nothing was downloaded, traced, photo-sourced or generated by an image model.
- Method: geometry, UVs, displacement detail, colour painting, rig and animation are generated by the scripts in
  `Art/blender/` (`crab_lib.py`, `crab_detail.py`, `crab_paint.py`, `crab_skel.py`, `crab_anim.py`,
  `crab_motions.py`, `build_crab.py`, `rig_animate_crab.py`) using Blender 5.2 LTS (GPL, headless) and numpy. The noise
  and cellular patterns are implemented in `crab_lib.py`; no texture libraries were used.
- Outputs: `Art/export/meshes/SK_FiddlerCrab.fbx`, `Art/export/anims/A_FiddlerCrab_*.fbx`,
  `Art/export/textures/T_FiddlerCrab_{BaseColor,Normal,ORM}.png`, previews in `Art/previews/`.
- Rebuild: see `Art/blender/README-crab.md`.
