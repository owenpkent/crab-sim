# Crab Sim

A crab simulator game. You are a crab. Scuttle, dig, pinch, molt, survive the tide.

## Status

Fresh UE 5.8 C++ scaffold. Compiles to an empty module with the lean renderer config from Coldbore.

## Layout

- `GAME.md`: design brief (what the game is, core loop, input model)
- `docs/`: design notes, sprint logs
- `Source/CrabSim/`: game module
- `Config/`: project ini files
- `Content/`: assets (LFS, see .gitattributes)
